# Findings ledger

One line per claim that has been tested, with its current verdict and the evidence. Unlike the
dated notes this file **is** kept current: when a later note changes a verdict, edit the row and
add the new note to its evidence. Read it before proposing an experiment, so settled questions
are not re-run by accident. `INDEX.md` is the chronological view of the same notes.

Verdicts: **DROP** = tested and falsified, do not retry without a new reason · **KEEP** = shipped
as a default · **OPT-IN** = shipped behind a flag, not default · **OPEN** = unresolved or
contested.

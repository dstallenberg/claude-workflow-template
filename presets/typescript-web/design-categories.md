### Missing User Flows
- Is the **core user journey** clearly defined? (landing → onboarding → primary action → retention)
- Are there enough **reasons to return** after first use?
- What does the **power user experience** look like?

### Interaction Gaps
- Features that are referenced but never detailed (e.g., "notifications" mentioned but no trigger rules, delivery channels, or preference UI)
- Interactions between features that haven't been thought through (e.g., how does search interact with filtering? How do permissions affect shared views?)
- Missing **feedback** — does the user know their action succeeded? Can they undo mistakes?
- **Edge cases** — empty states, error states, loading states, offline behavior

### User Experience
- **Onboarding** — how does a new user understand the product? Is the value proposition clear within 30 seconds?
- **Performance perception** — are there loading spinners where optimistic updates would work? Do lists paginate or infinite-scroll?
- **Accessibility** — keyboard navigation, screen reader support, color contrast
- **Mobile/responsive** — does the design work across screen sizes?

### Missing Capabilities
- Authentication / authorization flows
- Search and filtering
- Data export / import
- Settings and preferences
- Error recovery and undo
- Collaboration / sharing features
